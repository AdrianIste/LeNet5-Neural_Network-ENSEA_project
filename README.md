# Hardware for Signal Processing — ENSEA

This repository contains the work carried out for the Hardware for Signal Processing course at ENSEA.

The project focuses on CUDA programming and parallel computing, with practical exercises on GPU acceleration and neural network computations.

It also includes work on LeNet-5, a convolutional neural network used for handwritten digit recognition on the MNIST dataset.

The repository contains CUDA source files, a Jupyter notebook, and the weights and biases used by the neural network.
